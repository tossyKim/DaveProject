## 💻 주요 구현 코드

### 조준 시스템

플레이어의 입력을 확인하여 조준 상태를 변경하고 UI를 제어하는 기능을 구현했습니다.

```csharp
public bool isaim = false;
public GameObject aimUI;

void Update()
{
    if (Input.GetMouseButton(1))
    {
        isaim = true;
        aimUI.SetActive(true);
    }
    else
    {
        isaim = false;
        aimUI.SetActive(false);
    }
}
```

마우스 우클릭 입력을 기반으로 플레이어의 조준 상태를 관리하고, 조준 UI의 활성화 여부를 제어하도록 구현했습니다.

## 🧩 개발 과정에서의 문제 해결

프로젝트를 진행하면서 Unity와 C#의 동작 방식뿐만 아니라 Git을 활용한 프로젝트 관리 과정에서도 다양한 문제를 경험했습니다.

특히 Unity 프로젝트에서 자동으로 생성되는 파일이 Git에 포함되면서 발생한 충돌을 해결하는 과정에서 `.gitignore`의 필요성과 Unity 프로젝트의 버전 관리 방법을 학습했습니다.

또한 기능을 구현하는 과정에서 발생하는 오류를 단순히 수정하는 것보다 **오류의 원인을 확인하고 코드의 동작 과정을 추적하여 해결하는 것**을 중요하게 생각하며 개발하고 있습니다.
